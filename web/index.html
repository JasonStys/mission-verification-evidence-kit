How to use this kit & interpret its results

Choose a scenario and age policy, then evaluate. Green requires every declared linked test to pass with current source, definition and requirement revisions, within the age window, and every declared fault to have passing coverage. A later failed, skipped or errored attempt blocks its requirement. A release source mismatch blocks overall readiness.

Fixture timestamps are fixed for reproducibility, not today’s clock. The browser is read-only. Use the CLI to validate bounded JSON inputs, enforce a gate, or save an optional local SQLite history. Input and report exports are data only; this app never executes test commands or uploaded code. The separate verify-delivery CLI authenticates an existing secure-delivery demo release, not these fictional mission results.

Start from examples/recorder.json and see docs/USER_GUIDE.md and docs/SCHEMA.md. Human review remains necessary; omitted requirements and false declarations cannot be discovered by a matrix alone.
